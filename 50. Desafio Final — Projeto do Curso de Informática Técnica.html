Projeto Final: Sistema de Gestão Escolar

Este projeto consiste no desenvolvimento de uma aplicação para gestão de notas e presenças dos alunos do curso técnico.

Tecnologias Utilizadas

  • Desenvolvimento Web
    • HTML5
    • CSS3
  • Linguagens de Programação
    • JavaScript

Etapas do Desenvolvimento

  1. Levantamento dos requisitos do sistema.
  2. Criação da estrutura e páginas em HTML.
  3. Implementação das regras de negócio e validações.
  4. Testes e apresentação do projeto final.
