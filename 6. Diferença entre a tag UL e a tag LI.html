​Diferença entre a tag UL e a tag LI

​A tag UL (Unordered List) serve para definir o contentor principal de uma lista não ordenada, ou seja, indica que ali começa uma lista de itens com pontos (bullets).
A tag LI(List Item) é utilizada para definir cada item individual que fica dentro dessa lista.
